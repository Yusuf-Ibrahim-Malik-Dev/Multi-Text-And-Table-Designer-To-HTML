MULTI TEXT AND TABLE DESIGNER - ASP.NET WEB FORMS / .NET FRAMEWORK 4.8

Cara menjalankan:
1. Extract ZIP ke folder lokal.
2. Buka MultiTextTableDesigner.sln di Visual Studio 2022.
3. Pastikan workload ASP.NET and web development dan .NET Framework 4.8 Developer Pack terpasang.
4. Jadikan MultiTextTableDesigner sebagai Startup Project.
5. Jalankan dengan F5.

Default.aspx mempertahankan markup, CSS, dan JavaScript dari index.html. Asset lokal (Mammoth.js, PDF.js, worker, gambar dan file data) ikut disertakan. Fitur parsing dan editing dokumen tetap dijalankan di browser; code-behind tersedia untuk penambahan proses server-side. Build dan runtime perlu diverifikasi pada Visual Studio Windows.
